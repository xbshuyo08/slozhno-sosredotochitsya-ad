# Сложно сосредоточиться

Адаптивная страница о том, почему сложно концентрироваться и как вернуть внимание.

В проекте реализованы светлая и тёмная цветовые схемы, автоматическое переключение по системным настройкам и адаптивная галерея.

Репозиторий: https://github.com/xbshuyo08/slozhno-sosredotochitsya-ad

## Запуск

Откройте файл `index.html` в браузере.
